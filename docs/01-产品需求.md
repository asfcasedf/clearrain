# 01 — 产品需求

> 项目：晴雨（ClearRain）— 大学生心理健康测评系统
> 版本：v1.0（MVP）
> 状态：待确认

---

## 一、产品定位

面向高校学生的**心理压力自测工具**，通过 PSS-10 压力感知量表帮助学生了解自身压力水平，提供温和的反馈与建议。管理端供辅导员/心理老师查看群体数据、检索测评记录。

**核心价值**：低门槛、无压力、鼓励式自测，不制造焦虑。

## 五、核心业务规则

### 5.1 PSS-10 计分规则

- 共 10 题，每题选项：`0 从不` / `1 几乎从不` / `2 有时` / `3 经常` / `4 非常频繁`
- **正向题**（1, 2, 3, 6, 9, 10）：得分 = 选项分
- **反向题**（4, 5, 7, 8）：得分 = 4 − 选项分
- 总分 = 10 题得分之和，范围 0–40

### 5.2 标准化与等级

```
标准化分 Pt = (总分 / 40) × 100

Pt < 35        → 低压  🌿 晴
35 ≤ Pt < 65   → 中压  ⛅ 多云
Pt ≥ 65        → 高压  🌧️ 雨
```

> 等级语义色（绿/金/红）为功能色，具体色值待品牌配色方案确定后在 05-页面原型.md 中锁定。

### 5.3 结果页文案铁律

- 先说「这很正常」→ 再给建议 → 最后附免责声明「本测评不构成临床诊断」
- 低压：最近状态不错，像春天的微风
- 中压：这在大学生中很常见，你不是一个人
- 高压：你最近承受了不少，是时候给自己多一点关怀了

### 5.4 频控

- 学生可随时发起新测评，无强制间隔
- 记录保留全部历史，不覆盖

## 六、非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 列表接口响应 < 500ms，单页测评加载 < 1s |
| 安全 | 密码 PBKDF2 加密，JWT access 30min / refresh 7d，CORS 白名单 |
| 兼容 | 学生端移动端 375–414px，管理端 1366px+ |
| 可用性 | 所有操作有 loading / 失败有 toast，禁止静默失败 |
| 数据 | 开发 SQLite，生产 MySQL 8.0 |

## 七、明确不做（MVP 排除项）

- ❌ PDF 导出、预警提醒、阶段报告、操作日志
- ❌ 冥想放松室、心情树洞、每日打卡、心理科普
- ❌ 多量表（DASS-21、TIPI-C 等）
- ❌ AI 建议、关键词云
- ❌ 同年级均值对比
- ❌ 社交/评论功能

---

## 八、验收标准（MVP）

1. 学生可注册、登录、完成一次 PSS-10 测评并看到结果
2. 历史记录可查看，趋势图正确渲染
3. 管理员可登录、查看统计、管理用户启用状态、检索记录
4. 反向计分（4,5,7,8 题）计算正确
5. 禁用用户无法登录
6. 所有接口返回 `{code, msg, data}` 统一格式
