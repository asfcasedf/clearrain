## 二、表结构

### 2.1 用户表 `accounts_user`

自定义用户模型（继承 `AbstractUser`）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BigAutoField | PK | 主键 |
| password | CharField | max_length=128 | 加密后的密码（set_password） |
| last_login | DateTimeField | null=True | 最后登录时间 |
| is_superuser | BooleanField | default=False | 超级管理员 |
| username | CharField | max_length=150, unique | 学号（登录账号） |
| first_name | CharField | max_length=150, blank | （保留，未使用） |
| last_name | CharField | max_length=150, blank | （保留，未使用） |
| email | EmailField | blank | 邮箱（可选） |
| is_staff | BooleanField | default=False | 是否管理员（True=管理员） |
| is_active | BooleanField | default=True | 是否启用（False=禁用，无法登录） |
| date_joined | DateTimeField | auto_now_add | 注册时间 |
| nickname | CharField | max_length=50 | 昵称 |
| gender | CharField | max_length=10, choices | 性别：male / female / unknown |
| grade | CharField | max_length=20, blank | 年级，如 "2023级" |
| major | CharField | max_length=100, blank | 专业 |

**索引**：`username`（unique 自带索引）

**枚举**：
```python
GENDER_CHOICES = [
    ("male", "男"),
    ("female", "女"),
    ("unknown", "未知"),
]
```

### 2.5 测评记录表 `assessment_record`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BigAutoField | PK | 主键 |
| user | ForeignKey(User) | on_delete=CASCADE, related_name="records" | 测评用户 |
| scale | ForeignKey(Scale) | on_delete=PROTECT, related_name="records" | 所用量表 |
| total_score | IntegerField | | 原始总分（0-40） |
| standard_score | IntegerField | | 标准化分（0-100） |
| level | CharField | max_length=10, choices | 等级：low / medium / high |

**索引**：`user_id`、`scale_id`、`(user, -created_at)`（用户历史倒序）、`level`

**枚举**：
```python

    ("high", "高压"),
```

### 2.6 测评作答明细表 `assessment_answer`

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BigAutoField | PK | 主键 |
| record | ForeignKey(AssessmentRecord) | on_delete=CASCADE, related_name="answers" | 所属测评记录 |
| question | ForeignKey(Question) | on_delete=PROTECT | 题目 |
| answer | ForeignKey(Answer) | on_delete=PROTECT | 所选选项 |
| score | IntegerField | | 该题得分（已处理反向计分） |

**索引**：`record_id`、`question_id`

**说明**：`score` 存储计算后的得分（反向题 = 4 - 选项分），便于审计与复盘。

## 四、计分逻辑（Service 层实现）

```python
def calculate_score(answers: list[dict]) -> tuple[int, int, str]:
    """
    入参：answers = [{question_id, answer_id}]
    返回：(total_score 0-40, standard_score 0-100, level)
    """
    total = 0
    for ans in answers:
        question = Question.objects.get(id=ans["question_id"])
        answer = Answer.objects.get(id=ans["answer_id"])
        if question.is_reverse:
            total += (4 - answer.score)
        else:
            total += answer.score

    standard = round(total / 40 * 100)
    if standard < 35:
        level = "low"
    elif standard < 65:
        level = "medium"
    else:
        level = "high"
    return total, standard, level
```

## 五、约束汇总

- 用户 `username`（学号）唯一
- 量表 `code` 唯一
- 题目 `(scale, order)` 唯一联合约束
- 选项 `(question, order)` 唯一联合约束
- 测评记录 `user` + `created_at` 无需唯一（允许重复测评）
- 所有外键 `on_delete` 明确指定
- 软删除：不使用，用户禁用用 `is_active=False`
