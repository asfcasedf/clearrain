## 二、学生端页面清单（Vue 3 + Vant 4，移动端 375px）

| # | 页面 | 路由 | 核心功能 |
|---|------|------|---------|
| 1 | 登录页 | `/login` | 学号 + 密码登录 |
| 2 | 注册页 | `/register` | 学号、密码、昵称、性别、年级、专业 |
| 3 | 首页 | `/` | 问候语 + 最近结果卡片 + 开始测评按钮 + 趋势缩略 |
| 4 | 测评页 | `/assessment` | PSS-10 逐题作答，进度条，上一题/下一题 |
| 5 | 结果页 | `/result/:id` | 分数 + 等级 + 建议 + 分数条 + 免责声明 |
| 6 | 历史页 | `/history` | 记录列表 + ECharts 趋势折线图 |
| 7 | 我的 | `/profile` | 个人信息 + 修改密码 + 退出登录 |

### 关键交互要求

- **测评页**：逐题展示，未选选项时「下一题」禁用；最后一题按钮变「提交」
- **结果页**：先说「这很正常」→ 再给建议 → 最后附免责声明「本测评不构成临床诊断」
- **空状态**：无记录时显示温暖文案 + 引导按钮，禁止「暂无数据」
- **所有异步操作**：有 loading 状态，失败有 toast 提示

## 四、压力等级语义色（功能色，非品牌色）

这三个颜色对应压力等级语义，与品牌配色方案独立：

| 等级 | 语义 | 建议色向 |
|------|------|---------|
| 低压 | 安全/良好 | 绿色系 |
| 中压 | 注意/一般 | 金色/橙色系 |
| 高压 | 警示/需要关注 | 红色系 |

> 具体色值待品牌配色方案确定后统一调整。
