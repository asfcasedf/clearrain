# 06 — 开发路线

> 项目：晴雨（ClearRain）
> 版本：v1.0
> 原则：TRAE 写 docs，Cursor 写 src，文档未确认不动手

---

## 一、里程碑总览

```
M0 准备    → 用户：环境+工具+配色（部分待完成）
M1 文档    → TRAE：docs/01~07 + 原型        ← 当前阶段
M2 后端    → Cursor：骨架 + 认证 + 量表 + 测评 + 历史 + 管理
M3 前端    → Cursor：学生端 7 页 + 管理端 5 页
M4 联调    → 双方：接口联调 + 自测 + 修 bug
M5 验收    → 用户：全流程走通验收
```

**关键卡点**：TRAE 文档确认前，Cursor 不进入 M2；接口变更先改 docs 再改代码。

## 二、M2 后端任务拆解（Cursor）

### M2.1 项目骨架

| 任务 | 依赖 | 验收 |
|------|------|------|
| Django 项目结构 + 配置分环境（dev/prod） | 无 | `python manage.py runserver --settings=config.settings.dev` 启动成功 |
| requirements.txt | 无 | `pip install -r requirements.txt` 无报错 |
| 统一响应 `{code,msg,data}` + 全局异常处理 | 骨架 | 任意接口返回统一格式 |
| CORS + JWT 配置 | 骨架 | 跨域请求通过，JWT 中间件生效 |
| Pagination（StandardPagination） | 骨架 | 列表返回 `{results,total,page,page_size,total_pages}` |

### M2.2 认证模块（accounts app）

| 任务 | 依赖 | 验收 |
|------|------|------|
| User 模型（AbstractUser，扩展 nickname/gender/grade/major） | M2.1 | migrate 成功 |
| 注册接口 `POST /auth/register/` | User | 学号唯一校验，密码加密 |
| 登录接口 `POST /auth/login/` | User | 返回 access+refresh，禁用用户 403 |
| 刷新 Token `POST /auth/refresh/` | 登录 | 新 access 可用 |
| 个人信息 `GET/PUT /auth/me/` | 登录 | 仅本人可改 |
| 修改密码 `PUT /auth/password/` | 登录 | 旧密码校验 |

### M2.3 量表模块（scales app）

| 任务 | 依赖 | 验收 |
|------|------|------|
| Scale / Question / Answer 模型 | M2.1 | migrate 成功 |
| PSS-10 数据迁移（1 量表 + 10 题 + 每题 5 选项） | 模型 | migrate 后数据存在 |
| 量表列表 `GET /scales/` | 模型 | 返回 PSS-10 |
| 量表详情 `GET /scales/{id}/` | 模型 | 含题目+选项 |
| 学生端题目 `GET /scales/{id}/questions/` | 模型 | 不含 is_reverse |

### M2.4 测评模块（assessment app）

| 任务 | 依赖 | 验收 |
|------|------|------|
| AssessmentRecord / AssessmentAnswer 模型 | M2.3 | migrate 成功 |
| 提交测评 `POST /assessment/submit/` | 模型+量表 | 自动评分，反向计分正确 |
| 结果查询 `GET /assessment/records/{id}/` | 提交 | 返回分数+等级+建议 |
| 我的记录 `GET /assessment/records/` | 提交 | 仅本人，分页 |
| 趋势数据 `GET /assessment/trend/` | 提交 | 按时间正序 |

### M2.5 管理模块（admin 接口）

| 任务 | 依赖 | 验收 |
|------|------|------|
| 概览统计 `GET /admin/overview/` | M2.2+M2.4 | 用户数/测评数/高压人数正确 |
| 用户列表 `GET /admin/users/` | M2.2 | 分页+搜索 |
| 启用/禁用 `PATCH /admin/users/{id}/` | 用户列表 | is_active 切换 |
| 量表管理 `GET /admin/scales/` | M2.3 | 列表 |
| 题目 CRUD `/admin/scales/{id}/questions/` | M2.3 | 增删改查 |
| 记录检索 `GET /admin/records/` | M2.4 | 多条件筛选 |

## 三、M3 前端任务拆解（Cursor）

### M3.1 学生端（Vant 4）

| 任务 | 依赖接口 | 验收 |

## 五、验收标准（每阶段）

### M2 后端验收
- 所有接口返回 `{code, msg, data}` 统一格式
- 反向计分（4,5,7,8）计算正确
- JWT 认证生效，未登录返回 401
- 禁用用户无法登录
- 管理端接口仅管理员可访问
- 列表接口分页正确

### M3 前端验收
- 学生端 7 页 + 管理端 5 页全部可访问
- 所有请求走封装的 axios 实例
- 401 自动跳登录
- 异步操作有 loading，失败有 toast
- 学生端只用 Vant，管理端只用 Element Plus

### M4 联调验收
- 注册→登录→测评→查看结果→历史 全流程走通
- 管理端登录→概览→用户管理→题库→记录检索 全流程走通
- 反向计分结果与手工计算一致

## 六、风险与缓解

| 风险 | 缓解 |
|------|------|
| Cursor 未看 docs 直接编码 | 铁律：docs 是唯一事实来源，违反则回滚 |
| 接口契约理解偏差 | M4 联调阶段逐接口对照 04-API契约.md 验证 |
| 配色方案未定 | 05 页面原型先占位，不阻塞后端开发 |
| Git 无 remote | 先本地提交，用户配置 GitHub remote 后 push |
